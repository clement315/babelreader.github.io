# 2026-10-17 中文引號與書名號專項修復

掃描五部正文、補編附錄（共613個閱讀單元）、目錄、全書前言、部序與補編導覽。修復28,932處可辨識的OCR標點變體，涉及11,741個中文欄位；統計包含目錄、標題和內置示例中的重複文本。

典型修復：

- `r動物J`、`í動物J`、`「動物j` → `「動物」`。
- `《基本教理手冊))`、`《基本教理手冊>>` → `《基本教理手冊》`。
- `(<<物理學》卷三)` → `(《物理學》卷三)`，保留外層引用括號。
- 修復可確定為引號的 `I`、`1"`、`["`、`_I`，以及可確定為書名號的雙括號、斜線、波浪號等。

修復僅適用於中文欄位。不是將所有r、J、j、括號或羅馬數字一律替換；完整拉丁詞、拉丁正文、拉丁HTML、來源定位、節號與段落結構均保留。個別「付」「卜」等中文字形，在完整書名及章節上下文能確定它們是誤識標點時，恢復為相應的括號或書名號。沒有重新翻譯或全面訂正中文用字。

目錄、實際逐問資料與頁面內置文本同步更新，並設定新的內容版本，使讀者重新載入後請求新版本JSON。原有202筆PDF初修記錄繼續保留，與本次標點修復分開記錄。

`punctuation-pending.json` 記錄994個未配對標點的複核線索（可能包含跨段引文和嚴重亂碼）。這些線索並不等於994個已確認錯誤；無法從現存文字確定邊界時，需核對原掃描頁，不據拉丁文補造中文。因此本次修復不代表全書已逐字校畢。

驗證包括：全部JSON可解析；613個閱讀單元、3,125節及39,507個雙語列完整；除中文欄位與版本資訊之外的全部資料與修復前雜湊一致；第一問內置資料與逐問JSON完全相同；修復規則再次執行不產生額外改動；常見錯誤與合法拉丁詞、數字、括號、巢狀引文均有回歸檢查。
