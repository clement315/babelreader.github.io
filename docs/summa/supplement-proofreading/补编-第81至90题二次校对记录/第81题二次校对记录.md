- 校订：我解答如下:人無須靠復活來獲得最初的完美（perfectio prima）。這種完美在於人性所需的一切都齊備（integritas），人在現世藉著自然原因（causa naturalis）的作用就能達到。人之所以需要復活，是為了獲得最後的完美，也就是達到最後目的。因此，凡旨在產生或保存人性最初完美的自然活動，在復活後都要止息。這些活動包括人的動物性生活、元素間的相互作用（actiones mutuae），以及天體的運行。因為飲食、睡眠和生育都屬於動物的生活，也都屬於人性的原始完美，在未來的肉身復活後，將沒有這些行為。
