# 补编第23题二次校对记录

参照首次校对记录及所列底本页码。

第三節正解補出代詞以明確指受絕罰者使人與自己同受絕罰，屬語意修訂。

## SUPPL.q023.a003.sed_contra

- 原文：1.除非人對某人有治權，否則不能寬赦他的大罪。可是，任何的司鐸都能寬赦與受絕罰者的交往。所以，與受絕罰者的交往並不是大罪。
2.此外，《申命紀》第二十五章2節說: 「當面按照他的罪，照數鞭打」。可是，按照共同的習慣，與受絕罰者交往卻不應該受大罪之罰，反而是受小罪的罪。所以，與受絕罰者交往並不是大罪。
- 校订：1.除非人對某人有治權，否則不能寬赦他的大罪。可是，任何的司鐸都能寬赦與受絕罰者的交往。所以，與受絕罰者的交往並不是大罪。
2.此外，《申命紀》第二十五章2節說: 「當面按照他的罪，照數鞭打」。可是，按照共同的習慣，與受絕罰者交往卻不應該受大罪之罰，反而是受小罪的罰。所以，與受絕罰者交往並不是大罪。

## SUPPL.q023.a003.respondeo

- 原文：我解答如下:有些人主張，凡人與受絕罰者交往，或交談，或第二節所禁止的任何形式，除了法典(參閱第一節正解)所許可的情況以外，都犯大罪、都是不合法的。可是，人與受絕罰者說一句很短的話就犯大罪，未免太嚴苛;而且，受絕罰者會為許多人設下受害的陷阱，使成為他們的同伴。所以，更可靠的意見認為:他並不總是犯大罪，而只在恭敬天主的行為上，或在輕視教會上，參與他的罪過行為時，才犯大罪。
- 校订：我解答如下:有些人主張，凡人與受絕罰者交往，或交談，或第二節所禁止的任何形式，除了法典(參閱第一節正解)所許可的情況以外，都犯大罪、都是不合法的。可是，人與受絕罰者說一句很短的話就犯大罪，未免太嚴苛;而且，受絕罰者會為許多人設下受害的陷阱，使他們成為自己的同伴。所以，更可靠的意見認為:他並不總是犯大罪，而只在恭敬天主的行為上，或在輕視教會上，參與他的罪過行為時，才犯大罪。
