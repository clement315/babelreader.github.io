## a001.arg1

人種仟麼 → 人種什麼；獲得放果 → 獲得效果。

- 原文：《迦拉達書》第六章7節說: 「人種仟麼，就收什麼」。可是，如果一人由於他人的救助而獲得放果，那麼他就由他人所播的種子而收穫果實。所以，人由於他人的救助，自己一無所得。
- 校订：《迦拉達書》第六章7節說: 「人種什麼，就收什麼」。可是，如果一人由於他人的救助而獲得效果，那麼他就由他人所播的種子而收穫果實。所以，人由於他人的救助，自己一無所得。

## a001.arg3

善工是有的勞 → 善工是有功勞；這種善正是 → 這種善工是。

- 原文：善工是有的勞的，也是值得頌揚的，即是因為這種善正是自願的行為(voluntarium)。可是，人卻不可能由另一人的善工而受頌揚。所以，人的善工也不可能是他人的功績。
- 校订：善工是有功勞的，也是值得頌揚的，即是因為這種善工是自願的行為(voluntarium)。可是，人卻不可能由另一人的善工而受頌揚。所以，人的善工也不可能是他人的功績。

## a001.respondeo

而撞得真福 → 而獲得真福；藉著所禱 → 藉著祈禱；所禱者得到 → 祈禱者得到；一人的苦工 → 一人的善工；而使他人撞得永生 → 而使他人獲得永生；賞問他 → 賞賜他；光榮的中目稱準備 → 光榮的相稱準備；他人的苦工 → 他人的善工；我們所折求 → 我們所祈求；t(li;{苦工中的愛德 → 即是善工中的愛德；在天主仁 → 在天主上；articulus f、idei → articulus fidei。

- 原文：我解答如下:人的行為可能有兩種目的。第一‘為獲得某種處境，例如:人因功勞行為而撞得真福的處境。第二，為獲得處境的某種後續效果，例如:人因某種行為而獲得某種附加的賞報(praemium accidentale)，或者免罰。人的行為可能以兩種方式產生這兩種功能:第一種，藉著功勞;第二種，藉著所禱。這兩種方式有所不同，因為功勞是根據正義;但是所禱者得到所求助的，只是因了被祈求者的慷慨大方。
所以應該說，為獲得某種處境，一人的苦工絕不能按功勞方式而有益於另一人的處境，即是由於一人的行為而使他人撞得永生。因為天主按照領受恩寵者的尺度，賞問他分享自己的光榮;可是，天主卻安排人由於自己的行為﹒而不是由於他人的行為，配得分享祂的光榮一一這裡指的是光榮的中目稱準備。可是當他還生活在世的時候，藉著祈禱，他人的苦工卻可能有益於另一人獲得某種處境，例如:一人可以為另一人祈求最初的恩寵。因為祈禱依賴我們所折求的天主的仁慈，我們所可能祈求的一切，都歸於天主的權下。

## a001.ad1

## a001.ad2

得到放果 → 得到效果；他人向我一起 → 他人同我一起。

- 原文：人為他人而行的善工，是他人得到放果。同樣地，他人向我一起行的善工，似乎也成為我的功績。因此﹒如果這人獲得他人因愛德、或者為他而行的善工效果，就不相反天主的正義。人類的正義似乎也是如此，所以可以代替他人做補贖。
- 校订：人為他人而行的善工，是他人得到效果。同樣地，他人同我一起行的善工，似乎也成為我的功績。因此﹒如果這人獲得他人因愛德、或者為他而行的善工效果，就不相反天主的正義。人類的正義似乎也是如此，所以可以代替他人做補贖。
