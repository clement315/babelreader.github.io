# 第二部第一集第43题二次校对记录

「論畏懼之原因」，共2节。底本 PDF 第2201至2204页，书内第430至433页。[首轮报告](../../../summa/pdf-proofreading/I_II-q043.md)

第一节释疑一谈的是遵守天主的命令。释疑二的 a principio amabatur 指与所怕之恶相反的善从起初就为人所爱，并非等到畏惧发生后才开始爱。

本轮修订正文2栏。

## I_II.q043.a001.ad1

底本 PDF 第2202页。

- 原文：前面第四十二題第一節曾說，畏懼本然並首先是針對其所逃避之惡的，而這與其所愛之某善相反。為此，畏懼本然是生於愛；次而是針對這惡因而得以發生者。如此，畏懼有時偶然引生愛，即如：人怕天主處罰，故遵守天主的誠命；繼而開始希望，希望又引生愛，如第四十題第七節已說過的。
- 校订：前面第四十二題第一節曾說，畏懼本然並首先是針對其所逃避之惡的，而這與其所愛之某善相反。為此，畏懼本然是生於愛；次而是針對這惡因而得以發生者。如此，畏懼有時偶然引生愛，即如：人怕天主處罰，故遵守天主的誡命；繼而開始希望，希望又引生愛，如第四十題第七節已說過的。

## I_II.q043.a001.ad2

底本 PDF 第2202页。

- 原文：那預期能加害於人者，首先使人生恨；但等到希望從他得到善之後，才開始有愛。所怕之惡所相反的善，從起初原就是被愛的。
- 校订：那預期能加害於人者，首先使人生恨；但等到希望從他得到善之後，才開始有愛。那與所怕之惡相反的善，從一開始就為人所愛。
