# 第二部第一集第16题二次校对记录

题名为「論運用——意志對導致目的者之行動」。首轮报告覆盖本题全部4节。底本 PDF 第1933至1938页，对应书内第162至167页。[首轮校对报告](../../../summa/pdf-proofreading/I_II-q016.md) · [前次疑点复核](../第二部第一集-第十六至二十题疑点复核.md)

第三节质疑二和释疑二分别明确「最後目的也能成為運用的對象」和「安止於目的」只在广义上称作运用。前轮据页图补回的句末标点已核对。

本轮修订2栏。

## I_II.q016.a003.arg2

底本 PDF 第1936页。

- 原文：此外，在那裡他又說：「運用是使東西由意志支配。」但沒有東西比最後目的更由意志支配。所以，能運用最後目的。
- 校订：此外，在那裡他又說：「運用是使東西由意志支配。」但沒有東西比最後目的更由意志支配。所以，最後目的也能成為運用的對象。

## I_II.q016.a003.ad2

底本 PDF 第1936、1937页。

- 原文：目的由意志支配，是為意志定止於目的。因此，定止於目的本來是享受，這樣則稱為目的之運用。但那導致目的者，不只由意志支配用於獲致目的，且是指向意志所安之另一個東西。
- 校订：目的由意志支配，是為意志定止於目的。這種安止於目的的行動本來是享受，也可按廣義稱為運用目的。但那導致目的者，不只由意志支配用於獲致目的，且是指向意志所安之另一個東西。
