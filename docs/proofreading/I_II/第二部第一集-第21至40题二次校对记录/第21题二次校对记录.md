# 第二部第一集第21题二次校对记录

「論人性行動善惡所生之後果」，共4节。底本 PDF 第2003至2010页，书内第232至239页。[首轮报告](../../../summa/pdf-proofreading/I_II-q021.md)

核对第一节「反之」的定义与奥斯定原作，出处为卷二十二第二十七章。释疑一据 monstra dicuntur esse peccata 还原主语，并以「過失」译出此处所论的自然作用的偏差。[奥斯定原作](https://www.newadvent.org/fathers/140622.htm)

本轮修订正文2栏。

## I_II.q021.a001.sed_contra

底本 PDF 第2004页。

- 原文：前面第十九題第四節曾指出，人性行為之善，主要繫於永恆之法律。故此，人性行動之惡，是由於不合永恆之法律。但這就是罪。因為奧斯定在《駁摩尼教徒福斯德》卷二十二第七章說：「罪惡是違反永恆法律的言語、行為、意念」。所以，人性行動因了是惡的而是有罪的。
- 校订：前面第十九題第四節曾指出，人性行為之善，主要繫於永恆之法律。故此，人性行動之惡，是由於不合永恆之法律。但這就是罪。因為奧斯定在《駁摩尼教徒福斯德》卷二十二第二十七章說：「罪惡是違反永恆法律的言語、行為、意念」。所以，人性行動因了是惡的而是有罪的。

## I_II.q021.a001.ad1

底本 PDF 第2004页。

- 原文：罪惡被稱為怪物，因為怪物是由自然行動之罪惡產生的。
- 校订：怪物被稱為自然的過失，因為這是自然作用發生偏差的結果。
