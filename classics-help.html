自己修改精读笔记

所有作品都可以直接编辑中文译文、施莱尔马赫译文和结构分析。阅读器保留希腊原文及逐词查询。

修改并保存

  1. 打开作品，选择要修改的页码，点击编辑笔记。
  2. 展开相应句子的句读笔记，直接修改三个文字栏。
  3. 点击保存本页，或按 Ctrl＋S（Mac 为 ⌘＋S）。看到“已保存到本机”后，刷新页面仍可读到修改。

本机保存只影响这台设备、这个浏览器和当前网站地址。更换浏览器、设备或清除网站数据前，请先导出备份。

备份或换设备

  1. 点击导出本作品修改，下载 ZIP 文件。每个作品分别导出。
  2. ZIP 内包含笔记备份.json、修改过的网页资料和上传说明.txt。
  3. 在另一台设备打开同一作品，点击导入备份，选择 ZIP 或其中的 JSON，即可恢复并继续编辑。导入会合并笔记，同一句以此次导入的内容为准。

自行更新公开网站

  1. 解压导出的 ZIP。
  2. 打开 网站的 GitHub 仓库首页，选择 Add file → Upload files。
  3. 把解压得到的 data 文件夹拖入上传区。核对文件路径应为 data/classics/作品名/页码.json。
  4. 填写修改说明，点击 Commit changes。待仓库的 Pages 部署完成后，网站会显示更新后的内容。

只需替换 ZIP 中列出的页面。其他仓库文件保留；笔记备份 JSON 与上传说明可自行留存。

本机保存不会自动修改 GitHub。导出及上传过程均可由你独立完成，无需再次让 Codex 处理。
