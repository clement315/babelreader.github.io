# 巴别塔图书馆
*Bibliotheca Turris Babel*

> Et idcirco vocatum est nomen eius Babel, quia ibi confusum est labium universae terrae…
>
> 因此这城名叫巴别，因为在那里变乱了天下人的言语
>
> ——[《创世记》11:9](https://vulgate.net/gn11-9)

巴别塔图书馆是一项个人翻译与阅读计划。它借用巴别塔的名字，希望通过翻译与注释，使散落在不同语言和时代中的文字，在中文中获得新的读者。

本馆计划逐步译介和整理以下文献：

- **古希腊作品**：诗歌、戏剧、哲学与其他古典文本。
- **古代注疏**：围绕古典作品形成的注释、解释与评议，借此理解古人如何阅读他们的经典。
- **教父作品**：早期基督教作者的部分著作。
- **格律学作品**：讨论古典诗歌格律、韵律与诗体的相关文献。

每部译作将尽可能注明所据底本，保留必要的篇章、节号或行号，并附译注与修订记录。译文将在持续阅读与校订中逐步完善，也欢迎读者提出订正与讨论。

愿这座小小的图书馆，为古典文字与今天的读者留下一处相遇之所。
